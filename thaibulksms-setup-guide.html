🎁 ทดลองฟรี 20 เครดิต ⚡ เชื่อม API ใน 5 นาที 🔐 OTP API สำเร็จรูป

💡 สิ่งที่ค้นพบจาก API Documentation

ThaiBulkSMS มี 2 วิธี ในการทำ OTP — เราสามารถเลือกใช้ OTP API สำเร็จรูป ที่ ThaiBulkSMS จัดการ OTP ให้ทั้งหมด หรือใช้ SMS API ส่งข้อความเอง (ที่เราทำไว้ในโค้ดก่อนหน้า) ก็ได้

เปรียบเทียบ 2 วิธี

เลือกวิธีที่เหมาะกับโปรเจค

📩 SMS API

ส่งข้อความ SMS เอง
  • เราสร้าง OTP เอง (ทำแล้ว)
  • ส่ง SMS ด้วย message ที่กำหนดเอง
  • Endpoint: api-v2.thaibulksms.com/sms
  • ใช้ Basic Auth (api-key : api-secret)
  • กำหนดชื่อผู้ส่ง (Sender) ได้
  • เหมาะกับ: ระบบที่มี OTP logic เอง

🔐 OTP API

ThaiBulkSMS จัดการ OTP ให้
  • TBS สร้าง + ส่ง OTP ให้อัตโนมัติ
  • TBS verify OTP ให้ด้วย
  • Endpoint: otp.thaibulksms.com/v2/otp/*
  • ใช้ Basic Auth เหมือนกัน
  • ง่ายกว่า — ลด code ที่ต้องดูแลเอง
  • เหมาะกับ: ใช้งาน OTP อย่างเดียว
ℹ️ ข้อแนะนำ

โค้ดที่เราทำไว้ใช้ SMS API (สร้าง OTP เอง + ส่ง SMS) ซึ่งเป็นวิธีที่ยืดหยุ่นกว่า เพราะเราควบคุม OTP logic ทั้งหมดเอง สามารถ fallback ส่งผ่าน LINE ได้ และไม่ต้อง refactor code ใหม่ทั้งหมด — ใช้ SMS API ต่อไปได้เลย

Sender Name คือชื่อที่จะแสดงเป็นผู้ส่ง SMS แทนเบอร์โทร เช่น "SPSC" หรือ "สหกรณ์"

⏱️ ระยะเวลาอนุมัติ: 5-7 วันทำการ
💰 ต้องซื้อแพ็กเกจตั้งแต่ 3,000 บาท ขึ้นไป
📝 ระหว่างรอ สามารถใช้ Sender เริ่มต้น "SMS." ได้เลย
💡 Sender ที่แนะนำ

ตั้งชื่อ Sender เป็น "SPSC" หรือ "สหกรณ์" เพื่อให้ผู้ใช้รู้ว่า SMS มาจากสหกรณ์จริง ไม่ใช่ spam ระหว่างรออนุมัติ ใช้ "SMS." แทนได้

5
นำ API Key ใส่ .env บน VPS

นำ API Key + Secret ที่ได้มาใส่ในไฟล์ .env ของ EasyLoan Backend

📄 .env — เพิ่มตัวแปรเหล่านี้
# ========== SMS OTP Config ==========

SMS_PROVIDER=thaibulksms

# จาก Step 2
SMS_API_KEY=paste_your_api_key_here
SMS_API_SECRET=paste_your_api_secret_here

# ชื่อผู้ส่ง (ใช้ "SMS." ก่อนถ้ายังไม่ได้จดทะเบียน)
SMS_SENDER=SMS.
⚠️ อย่า commit API key ขึ้น GitHub!

ตรวจสอบว่า .env อยู่ใน .gitignore แล้ว ไม่เช่นนั้น key จะหลุดไปบน public repository

6
ทดสอบ API

ทดสอบว่า API Key ใช้งานได้โดยเช็คเครดิตคงเหลือ

BASH / cURL 
# ทดสอบเช็คเครดิต (ใช้ Basic Auth)
curl -X GET https://api-v2.thaibulksms.com/credit \
  -u "YOUR_API_KEY:YOUR_API_SECRET"

# ถ้าสำเร็จจะได้:
# {"data":{"remaining_credit":20,"credit_type":"standard"}}
BASH / ทดสอบส่ง SMS 
# ทดสอบส่ง SMS (บัญชีฟรี ส่งได้เฉพาะเบอร์ตัวเอง)
curl -X POST https://api-v2.thaibulksms.com/sms \
  -u "YOUR_API_KEY:YOUR_API_SECRET" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "msisdn=66891234567&message=Test OTP: 123456&sender=SMS."

# เบอร์ใช้รูปแบบ 66XXXXXXXXX (ไม่มี +)
📌 รูปแบบ Authentication

ThaiBulkSMS API v2 ใช้ HTTP Basic Auth โดยใส่ api-key เป็น username และ api-secret เป็น password
→ โค้ด sms_service.go ที่ทำไว้ ต้องแก้ให้ใช้ Basic Auth แทน JSON body

🔧 ต้องแก้โค้ด sms_service.go!

จากที่ค้นพบใน API docs — ThaiBulkSMS API v2 ใช้:

  • ✅ Basic Auth (api-key เป็น username, api-secret เป็น password)
  • ✅ Content-Type: application/x-www-form-urlencoded (ไม่ใช่ JSON)
  • ✅ Endpoint: https://api-v2.thaibulksms.com/sms
  • ✅ Parameters: msisdn, message, sender

→ แจ้งผมเพื่อแก้โค้ดให้ตรงกับ API จริง
